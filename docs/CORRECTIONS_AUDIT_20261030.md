### Périmètre du premier lot d'images

Les mots proviennent des séries candidates existantes : pain/bain, poule/boule, poire/boire. Le manifeste distingue les attaques simples /p/–/b/ et le contexte /pw/–/bw/ de poire/boire ; la paire nom/action demande un jugement professionnel séparé. Ces contextes ne deviennent pas automatiquement des mesures équivalentes. Les illustrations ne qualifient aucune paire, sonde, autre langue ou variété.

Conserver le PNG source, les variantes, les empreintes, les consignes de génération, l'outil/date, les ambiguïtés et toutes les décisions humaines. Toute modification substantielle crée une nouvelle version ; anciennes passations et réserves restent intactes. L'extension au-delà de ce lot attend son examen.

### Passage complémentaire A09 — livraison des preuves après 46fd30e

La vérification finale a reproduit un second cas dans qualification.views.evidence_file : contrôle document.intact puis seconde ouverture pour FileResponse. Une empreinte déjà chauffée dans la requête, ou un remplacement entre le contrôle froid et la réouverture, pouvait livrer des octets différents du SHA conservé. Le correctif lit une seule fois avec une borne de 15 Mio, vérifie les octets lus et sert ces mêmes octets en mémoire ; HEAD conserve la longueur vérifiée sans corps. Les règles d'authentification, de variété et de révocation restent appliquées ; les documents intacts inconnus ou expirés restent accessibles comme archives aux seuls acteurs déjà autorisés, sans devenir utilisables comme preuve courante.

PostgreSQL local dédié : 74/74, aucun ignoré/échec/erreur, 66,950 s au journal (72,125 s avec migrations)**, comprenant les huit nouveaux cas et les modules qualification/médias/accès affectés. [Résumé du lot complémentaire](verification-20261030/postgresql-evidence-delivery-summary.json) ; journal complet privé conservé sur E:. Aucun document de production ni accès cloud utilisé pour ces tests. **Les suites globales de 430 tests ci-dessous n'ont pas été rejouées après ce correctif** ; aucun total additionnant ces lots chevauchants n'est annoncé.
