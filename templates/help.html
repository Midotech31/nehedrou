{% translate "Common questions" %}

{% translate "Why do the words stay the same when I change the interface language?" %}

{% translate "The interface translates menus. The clinician chooses the words and spoken variety. Change the caregiver instruction language in Preferences; filter content languages in the library." %}

{% translate "Why is audio unavailable in some activities?" %}

{% translate "These demonstration examples do not contain approved audio models. The caregiver reads the word. Clinical publication requires reviewed adult speech models and transcriptions." %}

{% translate "What does the practice result measure?" %}

{% translate "It records a choice between pictures and a participation report. It does not assess pronunciation, diagnose a disorder or establish therapeutic improvement." %}

{% translate "What if the activity is difficult or the child wants to stop?" %}

{% translate "Select Stopped, describe the difficulty if useful and contact the responsible clinician. Stopped attempts are excluded from the answer count." %}

{% translate "Why can I no longer open an activity?" %}

{% translate "The program may be completed, the profile archived, the content withdrawn or your access revoked. Ask the responsible clinician to check the program and your access." %}

{% translate "Who can read the family's reports?" %}

{% translate "Authorized caregivers and the responsible clinician can read the profile's reports. Professional observations are restricted to the responsible clinician. Practice management alone does not grant clinical access." %}

{% translate "Is this version available for clinical use?" %}

{% translate "This local demonstration uses fictional profiles and unvalidated examples. Clinical review, approved media and real deployment requirements must be completed before real use." %}
